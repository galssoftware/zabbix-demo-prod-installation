# Отказоустойчивая и защищённая инсталляция Zabbix

Этот репозиторий содержит практическое руководство по построению отказоустойчивой Zabbix-инфраструктуры и её последующему переводу на защищённые соединения с использованием TLS-сертификатов.

Проект разделён на два последовательных этапа:

1. Развёртывание базовой отказоустойчивой инфраструктуры.
2. Настройка сквозного шифрования и сертификатной аутентификации между компонентами.

Окружение предназначено для демонстрационных и учебных целей, а также может использоваться как основа для проектирования production-инсталляции. Конфигурация тестировалась на Ubuntu 24.04.

## Архитектура

В состав окружения входят девять серверов:

| Компонент | Серверы | Назначение |
|---|---|---|
| HAProxy и Keepalived | `haproxy01`, `haproxy02` | Единая точка входа, балансировка и управление виртуальным IP |
| Zabbix Server и Frontend | `zbx01`, `zbx02` | Отказоустойчивый сервер мониторинга и веб-интерфейс |
| Grafana | `grafana01`, `grafana02` | Визуализация данных Zabbix |
| PostgreSQL | `pg01`, `pg02`, `pg03` | Отказоустойчивый кластер базы данных |

Виртуальный IP, управляемый Keepalived, обеспечивает единый адрес подключения. HAProxy определяет текущий PostgreSQL Primary через Patroni API, направляет соединения на активную ноду и балансирует запросы чтения между репликами.

## Этап 1. Развёртывание отказоустойчивого окружения

Первая часть руководства описывает создание базовой HA-инфраструктуры:

- развёртывание трёхузлового кластера etcd;
- установка PostgreSQL и управление кластером через Patroni;
- автоматическое переключение PostgreSQL Primary;
- установка TimescaleDB для хранения истории Zabbix;
- настройка PgBouncer для управления соединениями с PostgreSQL;
- создание отдельных пользователей баз данных для Zabbix Server, Zabbix Frontend и Grafana;
- развёртывание двух Zabbix-серверов и настройка Zabbix HA;
- развёртывание двух экземпляров Grafana;
- настройка Grafana Zabbix Plugin и Direct DB Connection;
- установка HAProxy и Keepalived;
- балансировка Zabbix и Grafana;
- разделение подключений к PostgreSQL на Primary и реплики;
- настройка автоматического переключения виртуального IP;
- проверка отказоустойчивости компонентов.

На этом этапе создаётся работоспособная отказоустойчивая система, но внутренние соединения между HAProxy, Zabbix, Grafana и PostgreSQL ещё не полностью защищены TLS.

Подробная инструкция: [Базовая отказоустойчивая инсталляция](https://github.com/galssoftware/zabbix-demo-prod-installation/blob/main/zabbix-prod-non-secure-rus.md).

## Этап 2. Защита внутренних соединений

Вторая часть выполняется поверх уже развёрнутого окружения и добавляет внутреннюю PKI-инфраструктуру.

В рамках этого этапа:

- создаётся внутренний центр сертификации;
- для каждого сервера выпускаются отдельные ключи и сертификаты;
- сертификаты содержат необходимые DNS-имена, IP-адреса и SAN;
- сертификаты автоматически распространяются по серверам;
- HAProxy проверяет сертификаты Zabbix и Grafana;
- Zabbix Server, Zabbix Frontend и Grafana подключаются к PostgreSQL в режиме `verify-full`;
- PostgreSQL и PgBouncer переводятся на TLS;
- для аутентификации пользователей PostgreSQL применяется SCRAM-SHA-256;
- Grafana начинает обслуживать внутренние подключения по HTTPS;
- настраивается защищённое соединение между Zabbix Frontend и Zabbix Server;
- для Zabbix Agent 2 выпускаются отдельные сертификаты;
- соединения Zabbix Server ↔ Zabbix Agent защищаются TLS;
- выполняется проверка сертификатов, имён серверов и цепочки доверия.

В результате шифрование не заканчивается на внешнем HAProxy. Оно сохраняется на внутренних участках инфраструктуры:

```text
Пользователь ── HTTPS ──► HAProxy
                              │
                              ├── HTTPS + проверка сертификата ──► Zabbix
                              ├── HTTPS + проверка сертификата ──► Grafana
                              └── TLS passthrough ────────────────► PostgreSQL

Zabbix Server   ── TLS verify-full ──► PostgreSQL
Zabbix Frontend ── TLS verify-full ──► PostgreSQL
Grafana         ── TLS verify-full ──► PostgreSQL
Zabbix Server   ◄── TLS certificates ──► Zabbix Agent 2
```

Подробная инструкция: [Настройка защищённой инсталляции](https://github.com/galssoftware/zabbix-demo-prod-installation/blob/main/zabbix-prod-secure-rus.md).

## Порядок использования

Руководства необходимо выполнять последовательно:

1. Сначала развернуть базовую отказоустойчивую конфигурацию.
2. Проверить работу PostgreSQL, Zabbix, Grafana, HAProxy и Keepalived.
3. Установить Zabbix Agent 2 на серверы окружения.
4. Сгенерировать и распространить сертификаты.
5. Применить настройки защищённых соединений.
6. Проверить TLS, отказоустойчивость и мониторинг компонентов.

## Важное замечание

Репозиторий содержит демонстрационные IP-адреса, доменные имена, пароли и параметры доступа. Перед использованием в production необходимо заменить их собственными значениями, ограничить сетевой доступ и обеспечить безопасное хранение приватных ключей и учётных данных.
